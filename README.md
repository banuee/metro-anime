# Metro Anime

<p align="center">
  <strong>Android-приложение для просмотра аниме в эстетике Fluent Acrylic и Metro Design.</strong><br>
  Прямой HLS-стриминг без рекламы, агрегация библиотек Kodik и AniLibria, динамическая палитра из обоев и продвинутый жестовый видеоплеер.
</p>

---

## Особенности

- 📺 **Прямой стриминг без рекламы**: Прямое воспроизведение видеопотоков через Media3 / ExoPlayer. Никаких встроенных баннеров, сторонних веб-плееров или видеорекламы.
- 🌐 **Мультиисточники (Kodik + AniLibria)**:
  - Автоматический параллельный поиск по базам Kodik и AniLibria с объединением и дедупликацией;
  - Каталог популярных тайтлов и новинок сезона, обновляемый автоматически;
  - Прямой доступ к множеству вариантов озвучки и субтитров (AniLibria, Studio Band, SHIZA Project, 2x2, AniMedia и др.).
- 📑 **Поддержка длинных франшиз (Long Shonen)**:
  - Умное определение диапазона серий для каждой озвучки (например, *AniLibria (370–500 эп.)* vs *2x2 (1–500 эп.)*);
  - Приоритетная сортировка студий озвучки, стартующих с 1-й серии с максимальным покрытием эпизодов;
  - Быстрая навигация по пагинации диапазонов (`1–50`, `51–100`, `101–150`...) для аниме с сотнями эпизодов (*One Piece*, *Наруто*);
  - Переключение порядка серий (`1 → N` / `N → 1`).
- ❄️ **Fluent Acrylic дизайн (Metro)**:
  - Полупрозрачные акриловые карточки и доки с многоуровневым размытием;
  - Поддержка пользовательских обоев с настраиваемым радиусом StackBlur и цветокоррекцией сочности в стиле Hyprland;
  - Единый дизайн-код и типографика с [Metro Launcher](https://github.com/banuee/metro-launcher).
- 🎨 **Умная палитра акцентов**:
  - Автоматический экстрактор цветов из установленных обоев (квантование, цветовой скоринг, нормализация яркости/насыщенности);
  - Предустановленные классические цвета Metro (Cobalt, Emerald, Crimson, Amber, Violet, Cyan, Magenta, Lime).
- 📱 **Продвинутый плеер в стиле AniNet**:
  - **Настоящий Fullscreen Immersive**: автоматическое скрытие системных панелей (Status Bar и Navigation Bar) при входе в плеер;
  - **Быстрая перемотка жестами**: двойной тап в левой части экрана (-10 сек) и в правой (+10 сек) с анимированным HUD-индикатором;
  - **Ускорение удержанием (Quick Speed Boost)**:
    - Зажатие левой половины экрана — воспроизведение на скорости **1.5×**;
    - Зажатие правой половины экрана — воспроизведение на скорости **2.0×**;
    - При отпускании пальца скорость плавно возвращается к нормальной;
  - **Акриловые капсулы управления**:
    - Верхняя левая капсула: назад, отключение звука (Mute), ползунок скорости от 0.25× до 3.0×;
    - Центральная капсула: быстрое переключение эпизодов;
    - Верхняя правая капсула: блокировка экрана от случайных нажатий, выбор качества (1080p, 720p, 480p, 360p);
    - Нижний плавающий док: плей/пауза, таймкоды, интерактивный таймлайн и переключатель масштабирования (Fit / Fill / Zoom / 16:9 / 4:3).
- 🚀 **Обновления по воздуху (GitHub OTA)**:
  - Встроенная проверка релизов через GitHub API;
  - Отображение чейнджлога новой версии;
  - Фоновая загрузка APK с индикатором прогресса и запуск установки через Android FileProvider.

## Сборка и установка

### Требования
- JDK 17+
- Android SDK 35 (minSdk 26 — Android 8.0+)
- Gradle 8.x+

### Сборка отладочной версии (Debug)
```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### Сборка релизной версии (Release)
Для сборки подписанного релизного APK укажите параметры хранилища ключей в `local.properties`:
```properties
metro.storeFile=/home/user/.config/metro-launcher/metro-release.keystore
metro.storePassword=your_password
metro.keyAlias=metro
metro.keyPassword=your_password
```
Запуск сборки:
```bash
./gradlew assembleRelease -x test
# Собранный файл: app/build/outputs/apk/release/app-release.apk
```

### Автоматическая публикация релизов на GitHub
Скрипт сборки, создания git-тега и выгрузки APK в GitHub Releases:
```bash
./tools/release.sh "Описание изменений релиза..."
```

## Архитектура и стек

- **Язык**: Kotlin
- **UI**: Jetpack Compose, Material 3, Material Icons Extended
- **Медиаплеер**: AndroidX Media3 (ExoPlayer + HLS extension)
- **Изображения**: Coil Compose
- **Сеть & Данные**: OkHttp 3, Gson, Jetpack DataStore Preferences
- **Архитектура**: MVVM, Kotlin Coroutines & StateFlow
- **Провайдеры контента**: AniLibria REST API, Kodik API / Embedded Scraper
